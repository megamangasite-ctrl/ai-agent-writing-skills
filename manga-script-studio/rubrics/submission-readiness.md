# Submission readiness · evidence gates

Judge the **specific entry**, edition and version in hand. Artistic quality and potential audience reach receive separate editorial assessments.

| Requirement state | Assign when | Evidence to keep |
| --- | --- | --- |
| Pass | Official requirement and inspected or creator-confirmed facts agree | Specific clause or supplied rule, version, check date and matching project fact |
| Fail | A required item is missing or a fact conflicts with the rule | Contradiction plus whether a correction is possible for this entry |
| Unknown | A material rule, fact or interpretation is unavailable or conflicting | Exact question, missing source or project evidence, and who can resolve it |
| N/A | The edition or category explicitly makes the item inapplicable, or the condition clearly does not arise | Clause or facts that justify exclusion |

### Overall status in decision order

1. **Unknown — target needed.** No edition or category has been named. Return a reusable matrix and request the target if the creator wants an eligibility decision.
2. **Blocked.** A verified condition disqualifies the proposed entry in this edition, such as a closed window for a new submission or prohibited AI use documented in the submitted work. State the rule and project fact. Changing a declaration cannot change how work was made.
3. **Hold.** The target exists and a material Unknown or fixable Fail remains. Give the remedy or the precise question for the organizer. A missing lettered manuscript can be a fixable failure of the current packet. Keep unresolved preview permissions attached to the proposed public cut.
4. **Ready for creator review.** Every applicable requirement passes, each N/A is justified, and the required packet exists and has been inspected. Identify the exact files and version reviewed. The organizer makes the acceptance decision.

**Worked distinction.** In a fictional edition requiring 8–12 finished pages, a creator provides an eight-page script. The length can be planned within range, but the finished-manuscript row is Fail and the packet is on Hold. If the same edition explicitly excludes AI-scripted entries and the creator confirms the script was AI-generated, the proposed entry is Blocked. Do not erase that fact by reformatting the file.

**When rules change.** Reopen the relevant rows if a newer official amendment, a new version of the work, or a public release changes the evidence. A prior edition's answer cannot automatically clear a new one.
