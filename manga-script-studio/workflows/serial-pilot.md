# From a series promise to a pilot

**Start with** the premise, audience, requested pilot length, likely installment size and any constraints on cast, settings or release. If the run length is unknown, differentiate the next two installments and leave the horizon flexible.

1. Use [concept and hook](../skills/manga-concept-hook/SKILL.md) and [genre adaptation](../skills/manga-genre-adaptation/SKILL.md) to name the pleasure people could return for. Write a repeatable situation and a durable source of variation. “They solve another mystery” needs a changing relationship, cost or rule.
2. Use [character psychology](../skills/manga-character-psychology/SKILL.md) and [arc planning](../skills/manga-arc-planning/SKILL.md) to choose a pilot-scale desire, a tactic that fails and a different action that settles the local question. Make the settlement visible to the returning cast.
3. Open the [series ledger](../templates/series-ledger.md) with the [serialization skill](../skills/manga-serialization/SKILL.md). Mark what is paid today, what changes because of it, and exactly where a longer promise will next be serviced. Sketch the next two cases with different pressures. Mark projected events as planned.
4. Map the pilot to its page count. With [pacing](../skills/manga-page-turns/SKILL.md) and [visual writing](../skills/manga-visual-writing/SKILL.md), script the pilot when requested. Add one re-entry image for the next chapter. Make it new evidence for a returning reader while orienting a late arrival.
5. Read the pilot as if a second chapter were months away. Identify the unit of satisfaction the reader already received, the new question that grows out of it, and the cast or location demands on the artist. If every chapter ends on interrupted danger, try an invitation, a changed rule or a debt willingly taken.

**Deliver** the requested pilot or pilot plan and a concise ledger for the chosen horizon. If a metric or cliffhanger is offered as evidence of retention, identify the source and comparison group. Otherwise describe the return mechanism as an editorial hypothesis.
