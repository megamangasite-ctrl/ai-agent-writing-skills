# Repair a draft without losing its voice

**Start with** the supplied pages, desired effect, known display, protected material and scope. For a critique-only brief, return notes. For a repair brief, return the revised passage itself.

1. Let an [editorial cold read](../skills/manga-editorial-critique/SKILL.md) locate the first point where the intended inference breaks. Read without the synopsis if possible. Record what a newcomer can know on either side of that point and one thing the draft already does well.
2. Route the first cause. Use [page turns](../skills/manga-page-turns/SKILL.md) if the answer is physically visible early, [visual writing](../skills/manga-visual-writing/SKILL.md) if staging is unreadable, [dialogue](../skills/manga-dialogue-subtext/SKILL.md) if balloons duplicate or obscure the image, and [payoff](../skills/manga-emotional-payoff/SKILL.md) if a clear event carries little feeling.
3. Draft the smallest viable repair. Show before/after at the affected panel IDs. If a repair adds a panel or page, reconcile the total, balloon order, facing pairs and evidence for the ending. Keep locked dialogue and protected ambiguity intact.
4. Reread the repaired sequence in context. State an observable test such as “At P3.4 the reader can tell whose shoe it is, but can name the dancer only after P4.1.” If actual art is unavailable, distinguish a script-level check from a pending thumbnail check.

**Deliver** the patch or [editor's letter](../templates/editorial-letter.md), one side effect to check, and the evidence that would justify reopening the change. Use the [craft rubric](../rubrics/artistic-craft.md) when the user needs a full assessment. A one-panel repair seldom needs a complete scorecard.
