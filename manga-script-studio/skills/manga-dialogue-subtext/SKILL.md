# Dialogue and subtext

Read the scene for who is allowed to ask for what. Mark each speaker's immediate aim, what the other person can refuse, and which fact neither wants to name. Work against the existing art and available balloon space.

1. Give each important line a tactic, such as offering an object, correcting a measurement, or answering an easier question. Make rejoinders respond to the tactic. Vary sentence length, register, interruption and what each character notices. Preserve supplied dialect thoughtfully and verify consequential translations.
2. Cross out any line that narrates visible action. Restore it only if it lies, reframes the image, establishes a voice, or supplies needed information. For “I don't want you to leave,” a locksmith might ask “Want the spare back?” while keeping it on her ring. The reply can be a hand closing over the ring.
3. Place balloons in reading order with clear speaker tails or off-panel labels. Let a pause or interrupted line occupy actual panel space when the response depends on elapsed time. If lettering covers the acting, cut a clause, move information earlier, or split the beat where a new tactic begins.
4. Read aloud once, then cover the names and read the exchange again. If both voices sound interchangeable, revise their strategies before adding verbal tics. A cold translation should preserve the intention of a joke or honorific as well as its literal content.

**Deliver** the revised exchange in panel context and mark the reading order. When useful, give one silent alternative and what information it trades away. If dialogue is locked, revise staging or balloon placement within the fixed text. Use the [script page](../../templates/script-page.md) for the letterer's handoff.
