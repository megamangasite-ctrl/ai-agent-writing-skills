# Manga Script Studio

A downloadable workshop for writing manga with an AI agent. Bring a premise, a troublesome spread, a season outline, or a draft you want a jury to take seriously. The pack takes the work as far as the requested deliverable.

## Start in a minute

1. Unzip the archive. Keep the complete `manga-script-studio` folder together so its internal links resolve.
2. Give your agent access to that folder and ask it to read the root [SKILL.md](SKILL.md). If your agent imports folder-based skills, import the complete folder as one skill. Its entry point opens the 14 nested specialist files by relative path, so using it does not require automatic discovery of nested skills.
3. Paste a brief. In a chat that only accepts attachments, attach the root file, the specialist files it selects, and the linked worksheet or example you want to use. A pasted file cannot open sibling files on its own.

> Use Manga Script Studio to write a 12-page, right-to-left print one-shot. A bicycle mechanic has one evening to teach her father to ride before he moves away. He taught the whole neighborhood and has kept his own fear a secret. Make it funny. Let him refuse help once and ask for it in his own way. Give me the full page-and-panel script and one spoiler-safe preview. The first story page stands alone on the left.

Already have pages? Try “Keep my ending and every line of dialogue. Fix the reveal on the attached facing pages. Give me revised panels and one sentence explaining the change.”

## Choose a starting point

| What you want to make | Start here | What you receive |
| --- | --- | --- |
| A finished short | [One-shot workflow](workflows/one-shot.md) | A complete arc and an artist-readable script within budget |
| A pilot that can sustain a run | [Serial workflow](workflows/serial-pilot.md) | A satisfying first installment and a record of what later chapters owe |
| A focused repair | [Revision workflow](workflows/revision.md) | Located evidence, the smallest effective rewrite and a test |
| A private preview or an entry packet | [Contest and discovery workflow](workflows/contest-and-discovery.md) | A truthful invitation or a rules-backed readiness assessment |

## See one decision all the way through

Read [The Back Half](examples/the-back-half.md), a six-page original about two performers inside a stage horse. Then open the [annotated pages](examples/annotated-reading.md) for the staging, a rejected line, a worked rubric assessment and an excerpt cut. The [phone version](examples/scroll-cut.md) rebuilds its central turn for a continuously scrolling screen. Editorial notes sit outside the artist's script so you can read it cold.

## What's in the folder

| Folder or file | Contents |
| --- | --- |
| [SKILL.md](SKILL.md) | Root agent instructions and the complete specialist index |
| `skills/` | Fourteen individually scoped skills, each with a standard `SKILL.md` entry point |
| `workflows/` | Four routes through the pack with handoffs and stopping conditions |
| `templates/` | Nine copyable worksheets for story, production, editing, discovery and submission |
| `rubrics/` | [Artistic craft](rubrics/artistic-craft.md), [reader discovery](rubrics/reader-discovery.md) and [submission readiness](rubrics/submission-readiness.md) |
| `examples/` | The artist's script, page-by-page commentary and scroll adaptation |

The core pack is plain Markdown and works offline. A real contest assessment needs the organizer's rules for the named edition, supplied by the creator or checked online. Artistic and discovery scores guide revisions. Virality and awards remain goals, with outcomes decided by readers, distribution and juries.
