# Manga Script Studio

Start with what the creator wants to put in someone else's hands. A premise, a page map, an artist-ready script, a critique, a promotional excerpt, and a contest packet have different finish lines. Deliver the requested object. Use the workshop sheets privately unless the creator asks to see process.

## Set the brief

1. Extract the intended reader, genre pleasure, medium, length, language, nonnegotiable story facts, and assets already supplied. Identify one moment or quality the creator especially wants to protect. When revising, keep their voice and ending unless the request opens them up.
2. Establish how the reader advances. For print, record binding, first story-page side and visible pairs. For a digital reader, distinguish a single-page tap from a continuous scroll. If unspecified and material to the draft, use a named, reversible working layout. Treat the mapped pairs as provisional until the real pagination is known.
3. If a named contest is a destination, inspect its current edition and AI-use rules before generating material intended for entry. If rules or authorship facts are missing, identify the dependency. Continue with permitted, useful work such as a checklist or a craft-only assessment. Ask a focused question only when the missing answer changes what can be made.
4. Keep a short working record of locked choices, flexible choices, the core dramatic question, and open evidence. Update changed facts once and carry them into later pages. The [brief worksheet](templates/brief-and-hook.md) is available for a new project.

## Resolve competing aims

Find one promise the actual pages can keep for a newcomer and one choice that rewards a second reading. If an easy-to-share image gives away that choice, move the excerpt earlier or change the crop. If the only truthful crop still needs the ending, use a premise-led invitation. If the creator is protecting first-publication eligibility, keep promotion at the draft stage until the rules support release. Pursue broad discovery and award-level craft as ambitions. Neither virality nor an award can be guaranteed.

## Return the work

- Honor the requested format and count. In a script, label every page or scroll beat and distinguish visible lettering from production notes. Keep the artist's freedom wherever composition does not carry essential information.
- For longer jobs, pass forward the latest page map, character decisions, plant/payoff locations, unresolved serial promises, and any publication constraint. For a line edit, return the revised line in context.
- Do one read for cause and emotion and one for what the eye can actually see. Repair the clearest failure within scope. State any material assumption or unverified condition briefly. Treat a simulated cold read as editorial judgment and reserve observed reader behavior for real feedback.
- To calibrate a draft, read the [six-page script](examples/the-back-half.md) on its own before opening the [annotations](examples/annotated-reading.md). Use the [scroll adaptation](examples/scroll-cut.md) when the display changes.
